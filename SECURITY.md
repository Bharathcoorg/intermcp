## Reporting a Vulnerability

The **InterMCP** project takes security vulnerabilities seriously.

If you discover a security vulnerability within InterMCP, please **do not open a public GitHub issue**. Instead, submit your confidential disclosure directly to the project security contact:

📧 **Security Reporting Contact**: `bharathbr0x@gmail.com`

Please include:
- A clear description of the vulnerability.
- Steps to reproduce or a minimal proof of concept.
- The potential attack vector and impact assessment.

Reports will be acknowledged within 24 hours. We will coordinate a private patch and security advisory before public disclosure.
